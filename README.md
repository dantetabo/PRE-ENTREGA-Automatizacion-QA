# Proyecto de Automatización de Pruebas

## Propósito del proyecto
Este proyecto forma parte de la preentrega del curso de Automatización de Pruebas.  
El objetivo es realizar pruebas automáticas utilizando **Selenium** y **Pytest** para comprobar el correcto funcionamiento de distintos flujos dentro de una página web.  
Además, se genera un reporte en formato HTML con los resultados de las pruebas ejecutadas.

---

## Tecnologías utilizadas
- Python 3.10 o superior  
- Selenium  
- Pytest  
- Pytest-HTML  
- Webdriver-Manager
